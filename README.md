# 自分満たしカード

「31日間チャレンジ達成カード」の続きのツール。毎日1つ「今日自分を満たしたこと」を書いてスタンプを押し、30日間続ける。

- 期間: **2026年11月1日(日)〜11月30日(月)の30日間**(全員共通。Code.gs と app.js の `PROGRAM_START_DATE` / `PROGRAM_LENGTH`)
- 受講生はアカウント登録不要。SkipFマイページの「呼び名」と同じ名前を入れるだけで開始でき、同じ名前で続きから再開できる
- 1日1つ、自由記述(300文字まで)。書く = スタンプを押す。押し忘れた日も遡って書ける
- 書いた内容は**匿名**で「みんなの満たしたこと」に表示される。いつでも見られる
- リアクション4種類(💗いいね / 🤝わかる / ✨元気もらった / 🌱やってみたい)。自分の投稿にはできない
- 管理者タブ(同じURL)で、全員の進捗と全投稿を見られる。不適切な投稿は「非表示にする」で、みんなの画面から消せる(本人の画面とスタンプは残る)
- 11/1より前に開くと「11/1(日)からスタート」と表示され、書き込めない
- 書きかけの文章は端末に自動保存される(画面を閉じても消えない)

## 技術構成

ビルド不要の静的サイト(HTML / CSS / 素のJavaScript)。GitHub Pagesにそのままpushするだけで公開できる。

- データはGoogle Apps Script経由でGoogleスプレッドシートに保存(`students` と `posts` の2つのシート。自動で作られる)
- 投稿者の名前・IDは、みんなの画面向けのAPIには含まれない(匿名)。名前が見えるのは、スプレッドシート本体と、管理者の合言葉を入れた管理者タブだけ
- 管理者の合言葉は **スクリプトプロパティ `ADMIN_PIN`** に保存する(GitHubには載らない)。サーバー側で確認するので、合言葉なしでは投稿の名前も、非表示操作もできない
- スプレッドシートのセルはすべて「文字列」の書式。`=` で始まる投稿が計算式として動いたり、日付に勝手に変換されたりしない

## セットアップ

### 1. Googleスプレッドシート + Apps Script

1. [sheets.google.com](https://sheets.google.com) で**新しい**スプレッドシートを作る(名前は例: 「自分満たしカード DB」。31日間チャレンジのスプレッドシートとは別のファイル)
2. 「拡張機能」→「Apps Script」を開き、中身を全部消して [`apps-script/Code.gs`](apps-script/Code.gs) の内容をすべて貼り付けて保存(Command + S)
3. 左の歯車「プロジェクトの設定」→ 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ: `ADMIN_PIN`
   - 値: 管理者タブに入る合言葉(31日間チャレンジとは別のものがおすすめ)
4. 右上「デプロイ」→「新しいデプロイ」→ 歯車(種類の選択)→「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 「デプロイ」→ 初回は許可の画面が出るので許可する → 表示された**ウェブアプリのURL**(`.../exec`)をコピー

### 2. 設定ファイル

[`config.js`](config.js) の `https://script.google.com/macros/s/xxxx/exec` を、コピーしたURLに書き換える。

### 3. 手元での確認(本物のスプレッドシートは使わない)

```bash
node scripts/serve.cjs --today=2026-11-05 --admin-pin=test1234
```

[http://localhost:8091/?today=2026-11-05](http://localhost:8091/?today=2026-11-05) を開く。`Code.gs` をそのまま疑似スプレッドシート上で動かすので、サーバー側のプログラムも含めて確認できる(`/__reset` でデータを初期化、`/__set?today=2026-11-10` でサーバー側の「今日」を変更)。

### Code.gs を更新したときは

Apps Scriptのコードを直したら「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン: 新バージョン」→「デプロイ」(「新しいデプロイ」はURLが変わるので使わない)。

### style.css / app.js を更新したときは

`index.html` 内の `style.css?v=1` / `app.js?v=1` / `config.js?v=1` の数字を1つ増やす(キャッシュを無視して読み直させるため)。

## GitHub Pagesへのデプロイ

1. GitHubで新しいリポジトリを作る(Public。例: `jibun-mitashi-card`)
2. このフォルダをpushする(`git remote add origin ...` → `git push -u origin main`)
3. リポジトリの `Settings` → `Pages` → `Source: Deploy from a branch` / `main` `/(root)` で保存
4. 数分後、`https://(アカウント).github.io/(リポジトリ名)/` で公開される

## 配るURL

LINEで配る場合は、URLの末尾に `?openExternalBrowser=1` を付ける。

例: `https://(アカウント).github.io/jibun-mitashi-card/?openExternalBrowser=1`
